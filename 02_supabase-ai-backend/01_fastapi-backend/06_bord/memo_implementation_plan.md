# 메모장 구현 계획서

## 1. 목표
메모를 작성하면 현재 날짜와 시간이 자동 저장되고, 저장된 메모는 첫 화면에 카드 형태로 정렬되어 보이며, 클릭하면 상세 내용을 확인할 수 있는 메모장 기능을 구현한다.

이 문서는 기획을 실제 구현 단계로 옮기기 위한 안내서이며, FastAPI 기준으로 작성한다.

## 2. 구현 범위

### 포함 기능
- 메모 생성
- 메모 목록 조회
- 메모 상세 조회
- 메모 수정
- 메모 삭제
- 작성 시각 자동 등록
- 첫 화면 카드형 목록 출력

### 제외 기능
- 로그인/회원가입
- 이미지 업로드
- 태그 검색
- 알림 기능

## 3. 데이터 구조

### 3-1. Memo 모델
```python
{
  "id": 1,
  "title": "오늘의 메모",
  "content": "회의 준비하기",
  "created_at": "2026-07-15 14:30:00"
}
```

### 3-2. 저장 방식
초기 단계에서는 메모를 메모리 딕셔너리에 저장한다.
- 장점: 테스트가 빠르다
- 단점: 서버가 꺼지면 데이터가 사라진다

나중에는 Supabase나 DB로 바꿀 수 있도록 구조를 단순하게 유지한다.

## 4. API 구조

### 4-1. 메모 목록 조회
- `GET /memos`
- 역할: 전체 메모를 반환
- 정렬: 최신순

### 4-2. 메모 생성
- `POST /memos`
- 역할: 제목과 내용을 입력받고 현재 날짜와 시간을 저장
- 반환: 생성된 메모 데이터

### 4-3. 메모 상세 조회
- `GET /memos/{memo_id}`
- 역할: 특정 메모 1개 조회

### 4-4. 메모 수정
- `PUT /memos/{memo_id}`
- 역할: 제목과 내용 수정

### 4-5. 메모 삭제
- `DELETE /memos/{memo_id}`
- 역할: 특정 메모 삭제

## 5. 화면 흐름

### 5-1. 첫 화면
1. 사용자가 페이지에 들어온다.
2. 저장된 메모 목록을 불러온다.
3. 최신 메모부터 카드 형태로 보여준다.
4. 각 카드에서 제목, 작성일시, 미리보기를 확인한다.
5. 카드 클릭 시 상세 화면이 열린다.

### 5-2. 작성 화면
1. 제목을 입력한다.
2. 내용을 입력한다.
3. 게시 버튼을 누른다.
4. 현재 날짜와 시간이 자동으로 붙는다.
5. 목록 화면으로 돌아가고 새 메모가 바로 보인다.

### 5-3. 상세 화면
1. 선택한 메모의 전체 정보를 보여준다.
2. 수정 또는 삭제를 할 수 있다.

## 7. 예외 처리
- 제목이 비어 있으면 에러 반환
- 내용이 비어 있으면 에러 반환
- 없는 메모를 조회하면 404 반환
- 없는 메모를 수정/삭제하면 404 반환

## 8. 가상 테스트 방향
파이썬에서 실제 서버를 올리지 않고도 로직을 검증하는 방식으로 테스트한다.

### 테스트 목표
- 메모가 정상적으로 생성되는지 확인
- 생성 시각이 자동으로 들어가는지 확인
- 목록 조회 시 순서가 맞는지 확인
- 상세 조회가 정상 동작하는지 확인
- 수정과 삭제가 정상 동작하는지 확인

### 테스트 방법
1. `TestClient`를 사용해 FastAPI 엔드포인트를 호출한다.
2. 메모 생성 요청을 보낸다.
3. 응답에 `created_at`이 들어있는지 확인한다.
4. 목록 조회 요청을 보내 새 메모가 보이는지 확인한다.
5. 상세 조회 요청을 보내 내용이 맞는지 확인한다.
6. 수정 요청 후 바뀐 값이 반영됐는지 확인한다.
7. 삭제 요청 후 다시 조회했을 때 404가 나는지 확인한다.

## 9. 테스트용 코드 구조

```

```

### 9-4. 테스트 예시 흐름
```python

    "content": "문서 작성"
})

assert "created_at" in response.json()["data"]
```
