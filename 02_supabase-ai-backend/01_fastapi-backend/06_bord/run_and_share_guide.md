# 메모장 실행 및 공개 가이드

## 1. 먼저 확인할 점
네, 지금 상태라면 **VS Code를 열어서 실행하는 방식이 맞습니다.**

다만 중요한 점이 하나 있습니다.
- VS Code에서 실행하는 것만으로는 **내 컴퓨터에서만** 접속할 수 있다.
- 다른 사람들이 보게 하려면 **외부에서 접속 가능한 서버**에 올려야 한다.

즉, 순서는 이렇게 보면 된다.
1. VS Code에서 먼저 로컬 실행 확인
2. 기능이 정상인지 테스트
3. 배포 서버에 올리기
4. 내 도메인 주소를 연결하기
5. 다른 사람들이 접속할 수 있게 공개하기

## 2. VS Code에서 실행하는 방법

### 2-1. 준비
- VS Code로 프로젝트 폴더를 연다.
- 터미널을 연다.
- 가상환경이 없다면 만든다.
- 필요한 패키지를 설치한다.

### 2-2. 실행 명령
아래처럼 FastAPI 서버를 실행한다.

```bash
python -m uvicorn app:app --reload
```

### 2-3. 확인 방법
- 브라우저에서 `http://127.0.0.1:8000` 또는 `http://localhost:8000`으로 접속한다.
- API 문서는 보통 `http://127.0.0.1:8000/docs`에서 확인할 수 있다.

## 3. 로컬에서 먼저 해야 하는 테스트
로컬 실행 후 아래를 확인하면 된다.
- 메모가 생성되는지
- 생성 시간(`created_at`)이 자동으로 들어가는지
- 목록이 최신순으로 나오는지
- 상세 화면이 열리는지
- 수정과 삭제가 되는지

## 4. 다른 사람들이 보게 하려면
내 도메인 주소를 쓰려면 보통 아래 둘 중 하나가 필요하다.

### 방법 A. 배포 서버 + 도메인 연결
가장 일반적인 방법이다.

흐름:
1. 코드를 배포 서버에 올린다.
2. 서버의 공개 주소를 만든다.
3. 내 도메인의 DNS를 그 서버 주소로 연결한다.
4. HTTPS를 설정한다.

이 방식이 가장 안정적이다.

### 방법 B. 집/내 PC를 그대로 공개
가능은 하지만 추천하지 않는다.

이유:
- PC를 계속 켜둬야 한다.
- 인터넷 환경이 불안하면 접속이 끊긴다.
- 보안 관리가 어렵다.

## 5. 내 도메인 연결 가이드라인

### 5-1. 준비물
- 구매한 도메인
- 배포할 서버
- 서버를 공개할 수 있는 주소

### 5-2. DNS 설정
도메인 관리 페이지에서 보통 이런 설정을 한다.
- `A 레코드`: 서버 IP로 연결
- `CNAME 레코드`: 서비스 제공 주소로 연결

예시:
- `www` -> 서버 주소
- `memo` -> 서버 주소

### 5-3. HTTPS 설정
외부 공개를 할 때는 HTTPS가 필요하다.
- 브라우저에서 안전하게 접속할 수 있다.
- 도메인 접속 시 경고가 줄어든다.

## 6. 공개할 때 꼭 지켜야 할 점
- 로컬 개발용 주소는 외부 공개 주소가 아니다.
- 비밀번호나 민감한 정보는 코드에 직접 넣지 않는다.
- 환경변수로 분리한다.
- 공개 전에 에러 페이지와 예외 처리를 확인한다.

## 7. 추천 진행 순서
1. VS Code에서 로컬 실행
2. `docs`에서 API 확인
3. 메모 작성/조회/수정/삭제 테스트
4. 배포 서버 선택
5. 서버에 업로드
6. 도메인 DNS 연결
7. HTTPS 적용
8. 외부 접속 테스트

## 8. 지금 바로 하면 되는 일
현재 단계에서는 아래처럼 진행하면 된다.
- VS Code에서 `app.py` 실행
- 로컬에서 기능 확인
- 그 다음 배포 방법을 정해서 내 도메인과 연결

## 9. 한 줄 정리
**VS Code에서 먼저 실행하는 건 맞고, 다른 사람들이 보게 하려면 별도의 배포와 도메인 연결이 필요하다.**
